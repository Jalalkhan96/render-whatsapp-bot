# License Policy — Sound Meme Engine

**Unknown license NEVER becomes free.**

| Status    | Meaning                                                              |
|-----------|----------------------------------------------------------------------|
| `free`    | License verified live from source metadata (CC variants, CC0, public |
|           | domain). Only `wikimedia-audio` results can earn this. Carries name, |
|           | license URL, and attribution text.                                   |
| `unknown` | User uploads (YouTube). Searchable and linkable, never downloaded by |
|           | this tool, never labeled free.                                       |
| `blocked` | Source filtered before results (or the whole source is a stub).      |

Downloads happen ONLY from `wikimedia-audio`, and every download writes a
`.license.json` sidecar with source, author, license status, and attribution.
YouTube is metadata + official watch links only — this tool does not rip
YouTube audio/video, period.
